Which door goes where?

  • Break This Build: this shared testing and development hub. It links projects; it does not merge their rules or runtimes.
  • The Weaver: a creative/provenance reading surface at /duet/. It is separate from the game controls.
  • DUET multiplayer: the temporary Railway room-code demo. DUET local recovery: /duet/play/, for one-device play or a computer opponent.
  • First Movement: the existing short browser prototype at ren-rhapsody/play/. The wider Ren/UEFN blueprint remains a concept, not a published Fortnite island.
  • PIXIE: the existing contributor guide. Its reviewed snapshots have their own dates; they are not live release acceptance.

Halloween stays the First Movement acceptance checkpoint: complete the existing scene, record iPad/touch and independent completion results, fix blockers, and publish findings. If those checks remain unmet, label the release a development showcase. Polyfork and ArtCraft are optional production studies; no 3D conversion is included in today's release scope.
