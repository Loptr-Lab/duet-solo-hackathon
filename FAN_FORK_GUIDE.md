# Fan Fork Guide

Duet is MIT-licensed and may be copied, modified, and redistributed under the terms in
[LICENSE](LICENSE).

## Before publishing

- Use a distinct name, logo, domain, cloud project, and social account.
- State: "Unofficial fan fork; not endorsed by Loptr Lab."
- Preserve the MIT copyright and permission notice.
- Keep this project labeled as a two-player, 8×8 experimental accessibility artifact.
  It is not the canonical four-player Veiled Dominion rules authority.
- Never reuse Loptr Lab credentials, production services, private data, research records,
  or participant information.

## Before deploying

1. Read [SECURITY.md](SECURITY.md) and [docs/DATA_GOVERNANCE.md](docs/DATA_GOVERNANCE.md).
2. Create a separate cloud project with budgets and alerts.
3. Keep Gemini optional; set request limits and provider quotas.
4. Configure Firestore least privilege, retention, and a deletion contact.
5. Use a dedicated Bluesky test account if posting is enabled.
6. Test locally with synthetic profiles and throwaway tokens.

Forking the code does not make the fork official canon, a Loptr Lab service, or part of
Loptr Lab's doctoral research.
